# 眩晕天梯 / VERTIGO LADDER

根据 `docs/Challenge_Game_Copy_Document.md` 的中文文案与产品定位制作的纯静态网页游戏。原文件为文案包，没有具体物理或操作设计；本实现采用旋转光标命中目标弧的时机挑战。

## 操作

光标进入绿色目标弧时点击圆盘、按空格 / Enter 或手柄 A（或右扳机）出手。接近白色中心刻度获得更高精度。P / Esc 暂停；切出页面自动暂停。每个目标 5 秒不出手会失误。出手后短暂锁定输入，避免重复触发。

## 模式

- **得分突击**：选择 1–120 阶，命中 8 次通关，3 条生命，可反复挑战。
- **闯关试炼**：从第 1 阶开始，共 10 阶，每阶 6 次命中，3 条共享生命。
- **一命模式**：从第 1 阶开始，一次失误结束，最高 120 阶。
- **每周天梯**：固定 ×2 风险，每周一按本地日期刷新种子，相同目标序列，3 条生命。排行来自当前浏览器的真实对局，展示最多最近 100 局中的本周前 30 条。
- **残影对决**：先在相同阶位和倍率完成得分突击，再与该纪录的真实输入时刻、角度和成绩对比。
- **钢铁种子**：每日固定种子，固定 ×2 风险，一命 120 阶，开始即消耗一次资格。清理浏览器数据可重置本地限制，无服务端防作弊。

×2 / ×3 风险会增加转速并缩小命中窗口。每升阶进一步加速、缩小窗口，每三阶反转方向。超过 100 阶使用「彼岸」分层，最高 120 阶。

分数 =（基础通关 + 时间奖励 + 精度得分）× 风险倍率 + 风格连击 + 连击维持。结算展示全部组成。完美通关要求所有命中均在窗口中心 15% 范围内且无失误。V 评级仅为本地高阶完美评级，不代表真实世界排名。

文案中提到的全服、地区、好友排行榜、服务端周榜奖励和推送需要后端。本静态版本提供明确标注的本机周榜，不生成虚构对手或排名；未启用联网专属成就。成就与身份按实际游玩解锁。

## 本地开发和验证

需要 Node.js 22+。在本目录运行：

```sh
npm install
npm start
npm test
npm run test:browser
```

本地地址 http://localhost:4174 。浏览器测试使用 Microsoft Edge，可通过 `TEST_URL` 指定线上地址。测试会在测试浏览器内注入引擎实例引用，用于稳定验证命中、失败和计分；生产代码不提供作弊接口。截图输出至 test-results。

游戏运行时不依赖外部库、字体或素材。音效通过 Web Audio 合成，需要用户交互才能播放。手柄要求浏览器 Gamepad API 支持，可能需先按一次实体按钮激活。振动受设备支持限制。

## 部署

GitHub 仓库默认分支 main，Pages Source 选择 GitHub Actions。`.github/workflows/pages.yml` 在推送后运行规则测试并发布六个静态资源。使用相对路径，支持 GitHub Pages 项目子路径。

所有纪录仅保存在当前浏览器 localStorage，不跨设备同步。分享成绩通过系统分享或剪贴板复制链接，不能作为受验证的在线排名凭证。
