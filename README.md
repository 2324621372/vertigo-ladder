# 眩晕天梯 / VERTIGO 3D

根据 `docs/Challenge_Game_Copy_Document.md` 的文案制作的 3D 悬空平台跑酷游戏。使用 Three.js / WebGL 2 实时渲染，包含透视相机、立体角色、平台厚度、星空与深渊。依赖随站点发布，无外部 CDN。

## 操作

角色自动前进。A / D 或 ← / → 左右移动，空格 / Enter 起跳，空中可以调整方向。手机按住左右按钮移动，点击跳跃按钮；手柄左摇杆移动、A 跳跃。P / Esc 暂停，切出页面自动暂停。

打开网址即显示实时 3D 背景与游戏菜单，进入游戏后场景铺满浏览器窗口，分数、生命和操作按钮叠加显示。右下角“全屏”可进入或退出浏览器全屏；浏览器不支持全屏 API 时仍铺满窗口。浏览器要求用户点击才能请求全屏，不会自动隐藏地址栏。

到平台前缘之前起跳，越过断层。着陆越靠中央，精度得分越高。红色方块为移动障碍，绕开或跳过；部分平台左右移动。坠落或碰撞扣命，剩余生命允许在最近平台重生。

## 模式与存档

- 得分突击：选择 1–120 的起始难度，跨越 8 个平台，3 条生命。
- 闯关试炼：10 个平台，3 条共享生命。
- 一命模式：一次失误结束，最多 120 个平台。
- 每周天梯：固定 ×2 风险，按本地日期每周一刷新固定种子，3 条生命。本机周榜。
- 残影对决：先完成同阶位、同倍率的得分突击，显示真实纪录的 3D 轨迹残影。
- 钢铁种子：每日固定种子、×2 风险、一命 120 平台，每天本地限制一次。

倍率提高跑速、收窄平台；阶位提高难度。基础、时间和精度奖励乘风险倍率，再加风格和连击奖励。记录、成就、设置仅保存在当前浏览器，不跨设备同步。3D 版使用独立存档，旧圆盘得分不参与比较。清理浏览器数据可重置本地每日限制；没有服务端防作弊或联网排名。

## 开发与验证

Node.js 22+：

```sh
npm install
npm start
npm test
npm run test:browser
```

本地 http://localhost:4174 。浏览器检查使用已安装的 Microsoft Edge，并可通过 `TEST_URL` 指定线上地址。测试覆盖真实跳跃物理、落地、障碍、坠落复活、确定种子和可通关性，以及桌面和手机界面。截图位于忽略提交的 `test-results/`。运行需要支持 WebGL 2 的浏览器；音效需要用户交互，振动与手柄取决于设备支持。
